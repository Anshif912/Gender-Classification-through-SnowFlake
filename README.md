# Gender Classification

## Project Description
A machine learning project that predicts gender using classification techniques. The dataset is stored and accessed using Snowflake.

## Objective
- Classify gender accurately
- Use cloud data warehouse (Snowflake) for data handling
- Build a reliable ML model

## Technologies
- Python
- Snowflake (Cloud Data Warehouse)
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Workflow
1. Data Extraction from Snowflake  
2. Data Preprocessing  
3. Exploratory Data Analysis  
4. Model Training  
5. Model Evaluation  

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

## How to Run
pip install -r requirements.txt  
jupyter notebook

- Improve model performance
- Use advanced algorithms
- Deploy as a web application
